# Viet Phuc Remix MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an end-to-end MVP featuring a Python AI pipeline that generates and aligns an anime character with an Ao Dai, and a Next.js frontend that renders the layered assets using GSAP transitions.

**Architecture:** A Python script uses the Gemini API and `rembg` to generate, process, and export layered PNG assets and JSON metadata. A Next.js frontend consumes these static assets in an `OutfitComposer` component, applying Framer Motion/GSAP for smooth transitions.

**Tech Stack:** Python 3 (google-genai, rembg, Pillow, OpenCV), Next.js 14 (React), Tailwind CSS, Framer Motion, GSAP.

**Spec:** `docs/superpowers/specs/2026-10-09-viet-phuc-remix-architecture-design.md`

## Global Constraints

- Python code must handle API limits gracefully and validate output directories.
- Next.js must use the App Router (`app/`).
- Frontend assets must strictly map to `public/assets/...` as generated by the Python pipeline.

## Review Focus

- API Failure: If Gemini returns an invalid image or API limit is reached, pipeline should halt gracefully and log an error. (Added to Task 2)
- Transparency Failure: If `rembg` fails to separate foreground properly, it should still export but warn in logs. (Added to Task 3)
- Missing Metadata: Frontend `OutfitComposer` must handle missing `garment.json` gracefully without crashing. (Added to Task 5)
